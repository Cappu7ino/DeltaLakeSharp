# Security Policy

DeltaLakeSharp is an experimental, incubating project. Please do not report security vulnerabilities through public GitHub issues.

## Reporting A Vulnerability

Use GitHub private vulnerability reporting when it is enabled for the repository. If private reporting is not available yet, contact the repository owner directly and include:

- affected package and version or commit
- operating system and runtime identifier
- reproduction steps
- impact assessment
- any known workaround

## Supported Versions

Before the first stable release, security fixes are handled on the default branch and the latest preview package only.

## Secret Handling

Do not include real credentials, SAS tokens, account keys, connection strings, or private table paths in issues, discussions, logs, tests, or documentation.
